# Requirements

## Functional
- User authentication and role-based access
- Create/import maintenance tasks
- Manage trains and schedules
- Manage corridors and asset availability
- Create and track block requests
- Detect train/block/resource conflicts
- Identify feasible task coordination
- Run schedule optimization
- Generate weekly and monthly plans
- Compare what-if alternatives
- Review/approve/reject plans
- Dashboard and analytics
- Audit important actions

## Non-functional
- Security
- Data validation
- Explainable recommendations
- Reasonable prototype performance
- Modular and extensible architecture
